# NICE CBO Website

Responsive multi-page static website for Northern Inclusion Community Empowerment (NICE) CBO.

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a public repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders in this package to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. GitHub Pages will publish the website at `https://YOUR-USERNAME.github.io`.

## Later custom domain
Purchase an available domain, then add it under Settings → Pages → Custom domain and configure the DNS records GitHub provides. The hosting can remain free; the domain registration is paid.

## Before launch
- Confirm all public contact and registration details.
- Replace the text-based NICE mark with the official logo artwork if desired.
- Upload only final, approved documents to the Documents page.
- Add authentic photos only with appropriate consent. Do not imply proposed activities have already happened.
- The contact form opens the visitor's email app; it does not store messages on a server.
